# Що допомагає таким, як я · PISA 2025 Україна

Інтерактивний інструмент на мікроданих PISA 2025 для України. Учень обирає свої умови (достаток родини, техніка вдома й у школі, звички навчання, безпека в школі) і бачить, як склалися результати в учнів із такими самими відповідями, скільки з них досягли базового рівня, і які дієві кроки підтверджені дослідженнями.

## Що робить бекенд

Serverless-функції Vercel у папці `api/`, дані в Upstash Redis:

| Ендпоінт | Що робить |
|---|---|
| `POST /api/visit` | анонімно зберігає обрані відповіді (раз за сесію, лише після взаємодії) |
| `GET /api/stats` | агрегована статистика: скільки людей пройшли, що обирають, які поради додають до плану |
| `POST /api/plan` | лічильник порад, доданих до плану |
| `POST /api/feedback` | «Чи корисна сторінка?» + коментар |
| `GET /api/feedback?key=ADMIN_KEY` | перегляд коментарів (якщо задано змінну `ADMIN_KEY`) |
| `POST/GET /api/share` | коротке посилання `/?r=<id>` з відповідями й планом |
| `GET /api/health` | чи підключена база |

Імен, контактів чи IP не зберігаємо (IP лише хешується для обмеження частоти запитів і ніде не записується надовго). Без підключеної бази сторінка працює повністю, просто без блоку «Що обирають інші відвідувачі».

## Деплой

1. Import цього репозиторію на vercel.com (Framework: Other, нічого не змінювати).
2. Project → Storage → Create Database → **Upstash for Redis** → Connect to project. Vercel сам додасть `KV_REST_API_URL` і `KV_REST_API_TOKEN`.
3. Redeploy.

Локально: `npm run dev` → http://localhost:3000 (база в пам’яті).

## Дані й метод

Учнівський файл PISA 2025 для України (7 105 учнів, у моделі 4 918). Вагована лінійна модель з усіма десятьма можливими значеннями і BRR-вагами. Деталі на сторінці в розділі «Як це пораховано».
